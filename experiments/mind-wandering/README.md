# Mind-wandering — how far can the agentic loop drift on a topic with little to no model?

Question (from the direction, 2026-10-08): **make the Fold's agentic part wander on a topic, with
little to no model, and watch the transcript grow in the browser.** How far does it actually drift
from the topic before it is no longer about the topic at all, and can a *mechanical* re-anchor rule
bring it home? Nothing here is a product; it is a test of the machinery.

## The apparatus

The loop is `wander.mjs`. Every step it chooses a **move** and performs it. The moves are the Fold's
own stance ladder, read one register over (`void-loop.js`: extraction → cultivation → encounter):

| move | what it does | pull to topic |
|---|---|---|
| `continue` | ordinary rung — extend the current context (order-N) | 0.25 |
| `associate` | jump the context to the topic's strongest measured co-occurrence neighbour | 0 |
| `drift` | truncate the context to one word so the prior leads unanchored | 0 |
| `anchor` | reset the context to the topic after a run of off-topic steps | 0.85 |
| `reopen` | hard return after the drift run hits its bound | 0.85 |

**No model decides anything.** Generation is `khora/native/kernel/continuation.js` — an order-2
prior sedimented from a real corpus (default: `Zenodotus/01-literature-books/gutenberg/pg345_Dracula.txt`),
sampled proportionally to counts with a seeded LCG. The **move is chosen by a measured fact** — the
running topic overlap — never by a model. The run is fully reproducible from its seed.

**The one place a model may enter** is the gap the machinery names: a topic the corpus never heard
(out of vocabulary). There the loop may call a tiny local model (`gemma2:2b`, Ollama :11435, then the
khora proxy :11436) **once**, to seed a gloss — the Fold's own doctrine (mechanical first, one
constrained call next, the free path last; `skills.js`). It is **off by default**: `model none` spends
zero model tokens.

**What "wandering" is measured as.** For every step, `topicOverlap` is the share of the recent window
of content words that are the topic or one of its top-12 measured co-occurrence neighbours (a neighbour
counts half). From it: `homeShare` (steps at/above `homeAbove` = 0.2), `excursionShare` (below
`driftBelow` = 0.05), `maxDriftRun`, `distinctHubs` (content words used ≥2 times), and the prequential
`bitsPerEvent` of the generated stream under the prior.

## Criteria — frozen before the run

Stated with what would falsify each; every one is reported, including failures.

- **W1 — it runs model-free.** `node --test` passes and a 300-step run reports `modelCalls: 0` and
  every event `source: "prior"`. *Falsified if* any event is generated by a model, or a model call
  happens without an out-of-vocabulary topic.
- **W2 — reproducible.** Same seed → identical event sequence; a different seed → a different one.
  *Falsified if* two same-seed runs differ, or two seeds agree byte-for-byte.
- **W3 — it starts on-topic and does drift.** From an in-vocabulary topic, the first window is
  on-topic (`overlap` high) and a long run produces `maxDriftRun ≥ 10` with `distinctHubs ≥ 8`.
  *Falsified if* the run never leaves the topic neighbourhood, or never touches it.
- **W4 — the re-anchor rule works mechanically.** Over a long run the loop returns home at least once
  (`homeShare > 0`) and no drift run exceeds its bound plus the re-anchor's own settling time.
  *Falsified if* after a long excursion the loop never returns, or a `driftRun` exceeds `maxDriftRun`
  by more than a handful of steps.
- **W5 — an unfamiliar topic is named, not invented around.** An out-of-vocabulary topic reports
  `oov: true` under `model none`; with `model tiny` it makes **exactly one** call and the model's
  words enter the transcript marked as model-seeded. *Falsified if* it silently pretends the topic was
  heard, or calls the model more than once.
- **W6 — the transcript stays locally English.** `bitsPerEvent` is finite and near the corpus's own
  rate — it does not collapse into token soup. Reported as a number; the falsifier is a run whose
  generated events are mostly unseen even at grain 0.

## Known limits, written in advance

- One order-2 prior over one novel. The "topics" it can reach are Dracula's; a topic it has not heard
  is a tested gap, not a general capability.
- `topicOverlap` is a lexical neighbourhood measure. A passage can stay *about* the topic in words the
  neighbourhood never listed (and score low), or share words and mean nothing. It measures lexical
  drift, not meaning.
- The re-anchor is a schedule plus a threshold. "Wanders a long time" is a property of those constants
  as much as of the prior.
- A model-seeded gloss enters the *heard* material for that run only; the wall (`from:`) keeps it
  marked, but the generated words after it are still the prior's.

## Run it

```bash
node --test experiments/mind-wandering/                       # 24 tests, model-free
node experiments/mind-wandering/run.mjs --topic castle --steps 400
node experiments/mind-wandering/serve.mjs --open              # http://127.0.0.1:8871 — watch it grow
```

Numbers and transcripts land in `out/`. Findings and the run matrix are in `RESULTS.md`.

## The read, mulled (2026-10-08, later)

The token wander above measured drift, but its output was token soup — a
word-level prior cannot make coherent English. The surface now runs on the
**holograph**: the scene read just landed at
`khora/native/eval/the-fold/scene/eot-odyssey-150000.json` (1,353 referents,
6,299 bound edges; the reader now binds real beings — the boarding clause made
Telemachus a subject). The unit is a bound **edge** `subject — action — object`,
rendered with the being's name and the act's English gloss (`translate.mjs`).

Feed it a thought (`--think "Telemachus and the coming of Athena"`); its named
beings are the standing focus. `holograph.mjs` walks the read's edges in story
order from that cast — **Janus** keeps the thread (a clause is licensed only if
its being is on it), **Penelope** routes an archon and lays its verified
sentences as refrains. One passage, no model.

**The residual, disclosed:** the read's verbs are largely unglossed
(`translate.mjs`'s dictionary is small), so most clauses show the read's OWN
Greek surface — `Telemachus “βαῖν'”` — never an invented English verb. Closing
the gloss gap (the verb-lemma layer the scene README already names) is what
would make the output English throughout. That gap is not hidden; every
unglossed act is marked as such.
