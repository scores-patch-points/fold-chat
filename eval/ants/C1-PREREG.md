## The change under test (all in a COPY, `eval/ants/c1/origin-fixed.mjs`; the vetoed file is never edited)
- **Fix 1 (gate):** the idle gate keeps `ORIGIN.minAtoms = 3`, except that a claim with >= 1 `fig:` atom AND >= 1 `name:` atom needs only 2 non-holon atoms (`ORIGIN.minAtomsSlot = 2`). Variant "min2-all" (A1's copy, unconditional minAtoms 2) is measured as a comparison arm, not proposed.
- **Fix 2 (route):** new `corroborateAnswer(claim, hits, {...})` called from `followClaim` after the footnote walk and the already-read `alongside` fail: take the search hits (not encyclopedias/mirrors/farms/Q&A/social: a host gate), read the first `ORIGIN.corroborateReads = 8` (concurrently, `readMs` each), keep the FIRST in search order for which `supportOf(claim, page)` is `same`; the claim is the ANSWER's atomic claim (`opts.answerClaim`, defaults to the sentence). Trail path: found-in, alongside, read (existing shape). The host gate is a declared table (A2's mirror/encyclopedia/farm/QA/social lists, copied into origin.js to avoid importing fold-chat-primary.js and its heavy tree) and is injectable (`admit`).
- **Fix 6 (locate):** `folded()` drops pronunciation segments (`/…/` or `[…]` containing IPA-block characters) and the `ⓘ` glyph, so the extract's text and the parse HTML's text agree on the Eiffel lead.
